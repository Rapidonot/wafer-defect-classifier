# Wafer-defect classifier on an ESP32-S3

The distilled 8-bit wafer-defect model (30 KB, 5 conv layers, test macro F1 0.9406) running on an ESP32-S3
microcontroller. It uses plain C with default settings and its outputs are identical to
the distilled model

## Results (measured on the board, 2026-10-23)

| | |
|---|---|
| Board | ESP32-S3 (QFN56 rev v0.2), 240 MHz  (default), one core, 2 MB PSRAM, 8 MB flash |
| Test wafers run on the board | 11,781 (the whole held-out test set) |
| Bit-exact with the Python integer model | **11,781 / 11,781** |
| Test macro F1 (from the board's outputs) | **0.9406** |
| Test micro F1 | **0.9703** |
| Time per wafer, network only | **251.3 ms** (min 251.2, max 251.3) |
| Round trip incl. USB transfer | 279 ms |
| Program size | 328,570 bytes of flash (25%), of which the model is ~30 KB |
| RAM used | 71,936 bytes (21%) |

Per-class test F1 on the board:

| Center | Donut | Edge-Loc | Edge-Ring | Loc | Near-full | Random | Scratch |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 0.984 | 0.996 | 0.942 | 0.985 | 0.961 | 0.849 | 0.976 | 0.831 |

For comparison, the paper's models: ResNet-18 0.9657 (11.2 M parameters, 44.7 MB) and Vanilla CNN 0.8573
(3.2 M parameters, 12.9 MB). Neither fits on this board's memory as 8-bit.

Raw numbers: `results/evaluate_20261023_1103.json`.

## Files

- `wafer_esp32/wafer_esp32.ino`: receives a wafer over USB, runs the model, sends back the result.
- `wafer_esp32/cnn.c`, `cnn.h`: the model in about 80 lines of plain C
- `wafer_esp32/model_data.h`: the model's weights, generated by `../2_distillation/export_c.py`.
- `esp32_host.py`: Mac side. `demo` (one wafer) and `evaluate` (the whole test set, or `--n` wafers).


## Reproduce

```bash
# weights (from the repository root)
cd 2_distillation && python export_c.py && cd ..
# build + upload (arduino-cli with Espressif's esp32 core 3.3.12)
arduino-cli compile --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,FlashSize=8M 3_esp32/wafer_esp32
arduino-cli upload -p /dev/cu.usbmodem2101 --fqbn esp32:esp32:esp32s3:CDCOnBoot=cdc,FlashSize=8M 3_esp32/wafer_esp32
# run
python 3_esp32/esp32_host.py demo --idx 2119
python 3_esp32/esp32_host.py evaluate
```
